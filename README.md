# Платформа управления IT-конференциями (Science & IT Conferences Platform)

Клиент-серверное веб-приложение, предназначенное для организации, планирования и проведения научных и IT-конференций, а также митапов и тематических секций.
Сервис решает проблему несогласованности процессов: он объединяет в едином пространстве поиск событий через интерактивный календарь, прозрачную подачу заявок на доклады (Call for Papers), модерацию программы и автоматическое формирование сетки расписания без накладок по времени и аудиториям.

---

## 2. Команда проекта и роли

- **Тимлид, Backend-разработчик, Database Engineer**: отвечает за архитектуру серверной части, проектирование схемы данных, миграции и бизнес-логику.
- **Frontend-разработчик**: отвечает за клиентское приложение, верстку календарной сетки, роутинг и интеграцию с REST API.
- **UI/UX-дизайнер, Project Manager**: отвечает за прототипирование экранов в Figma, ведение доски задач и контроль сроков спринтов.
