# График работ и Roadmap проекта Science & IT Conferences Platform

## Sprint 1 & 2 (До 29.09) — Чекпоинт 1 и 2
**Цель**: Формализация архитектуры, контрактов и запуск базового каркаса.
- Разработка детальных сценариев использования (Use Cases) в документации.
- Проектирование принципиальной ERD-диаграммы базы данных (10 таблиц, 3NF).
- Спецификация контрактов REST API (маршруты, DTO).
- Развертывание базовых скелетов Backend (ASP.NET Core) и Frontend (React).
- Первичный прототип интерфейса в Figma.
- Запуск «Hello World» приложений и валидация сетевой связности.

---

## Sprint 3 (30.09 – 13.10) — Формирование MVP
**Цель**: Интеграция базы данных, DevOps-инфраструктуры и базовых позитивных сценариев (Happy Paths).
- **Backend & DB**: Развертывание PostgreSQL, настройка Entity Framework Core. Генерация миграций и физическое создание реляционной схемы. Реализация контроллеров `Conferences` и `TalkSubmissions`.
- **Frontend**: Интеграция React с бэкендом, вывод афиши мероприятий. Создание интерактивной формы подачи доклада спикером.
- **DevOps**: Контейнеризация проекта (Dockerfile для фронтенда/Nginx) и сборка `docker-compose.yml` для развертывания проекта одной командой.

### Checkpoint 3 (14.10) — Защита MVP
- Первый смотр работающего приложения: демонстрация сквозного кейса (чтение афиши -> подача доклада в БД -> вывод списка докладов).
- Ревью кодовой базы и проверка DevOps-инфраструктуры.
- Сверка достижимости этапа MVP по Roadmap.

---

## Sprint 4 (15.10 – 25.10) — Идентификация и безопасность
**Цель**: Полноценная ролевая модель и маршрутизация.
- Реализация регистрации и авторизации пользователей (JWT-токены, хэширование паролей с солью).
- Настройка политик доступа (RBAC): разделение прав Слушателя, Спикера, Организатора.
- Внедрение строгих внешних ключей в EF Core для привязки создаваемых сущностей к `UserId`.

---

## Sprint 5 (26.10 – 05.11) — Расширенный UI и Модерация
**Цель**: Доработка интерфейса до финального дизайна.
- **Frontend**: Разработка интерактивной сетки календаря с переключением месяцев и привязкой событий к датам.
- **Модерация**: Разработка защищенной панели организатора с кнопками «Одобрить / Отклонить» заявки и сменой статусов.
- Завершение связки таблиц: распределение одобренных докладов по залам (`ScheduleSlots`).

---
