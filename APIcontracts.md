# Контракты REST API (API Specifications)

Спецификация описывает форматы взаимодействия между клиентской частью (React Frontend) и серверной частью (ASP.NET Core Web API). Обмен данными осуществляется в формате JSON.

---

## 1. Конференции (Conferences)

### 1.1. Получение списка конференций
- **URL**: `/api/conferences`
- **Метод**: `GET`
- **Описание**: Используется фронтендом для отрисовки событий в сетке календаря.
- **Query-параметры**: `?year=2026&month=10` *(опционально)*
- **Статус ответа**: `200 OK`
  
- **Пример тела ответа**:
```json
[
  {
    "id": 1,
    "title": "Science & IT Conf 2026",
    "description": "Ежегодная научная конференция по современным IT-технологиям.",
    "startDate": "2026-10-15T10:00:00Z",
    "endDate": "2026-10-17T18:00:00Z",
    "location": "Главный корпус / Онлайн"
  },
  {
    "id": 2,
    "title": "DevOps & Cloud Days",
    "description": "Митап по практикам CI/CD и наблюдаемости.",
    "startDate": "2026-10-22T11:00:00Z",
    "endDate": "2026-10-23T17:00:00Z",
    "location": "Аудитория 204"
  }
]
```

###1.2. Получение детальной информации о конференции
- **URL: `/api/conferences/{id}`
- **Метод: `GET`
- **Описание: `Загрузка полной карточки мероприятия при клике на него в календаре.`
- **Статус ответа: `200 OK (или 404 Not Found)`
  
- **Пример тела ответа:
```json
{
  "id": 1,
  "title": "Science & IT Conf 2026",
  "description": "Ежегодная научная конференция по современным IT-технологиям.",
  "startDate": "2026-10-15T10:00:00Z",
  "endDate": "2026-10-17T18:00:00Z",
  "location": "Главный корпус / Онлайн",
  "organizerId": 1
}
```

##2. Регистрация слушателей (Registrations)

###2.1. Запись на мероприятие
- **URL: `/api/conferences/{id}/registrations`
- **Метод: `POST`
- **Описание: `Регистрация авторизованного пользователя в качестве слушателя.`
- **Статус `ответа: 201 Created`
- **Пример `тела ответа:`
```json
{
  "id": 101,
  "conferenceId": 1,
  "userId": 5,
  "registeredAt": "2026-09-29T10:30:00Z",
  "status": "Confirmed"
}
Ошибки: 409 Conflict (если пользователь уже зарегистрирован).
```

##3. Заявки на доклады (Talk Submissions)

###3.1. Подача заявки спикером
- **URL: `/api/talk-submissions`
- **Метод: `POST`
- **Описание: `Отправка темы и тезисов доклада на модерацию организаторам.`
- **Тело запроса (JSON):
```json
{
  "speakerId": 3,
  "trackId": 2,
  "title": "Архитектура устойчивых веб-сервисов",
  "abstract": "Разбор паттернов Circuit Breaker и Retry на примере реальных сбоев."
}
```
- **Статус ответа: `201 Created (объект создается со статусом "Submitted").`

###3.2. Одобрение или отклонение заявки
- **URL: `/api/talk-submissions/{id}/status`
- **Метод: `PATCH`
- **Описание: `Модерация заявки организатором в панели управления.`
- **Тело запроса (JSON):
```json
{
  "status": "Approved"
}
```
- **Статус ответа: `200 OK`

  ##4. Сетка расписания (Schedule Slots)
  
###4.1. Получение программы докладов по залам
- **URL: `/api/conferences/{id}/schedule`
- **Метод: `GET`
- **Описание: `Формирование таймлайна выступлений внутри выбранной конференции.`
- **Статус ответа: `200 OK`
Пример тела ответа:
```json
[
  {
    "id": 10,
    "hallName": "Главный зал",
    "talkTitle": "Архитектура устойчивых веб-сервисов",
    "speakerName": "Алексей Смирнов",
    "startTime": "2026-10-15T11:00:00Z",
    "endTime": "2026-10-15T11:45:00Z"
  }
]
```
